AtlasFlow: Real-Time Logistics Control Tower

Streaming & Real-Time Data Engineering · Completed · run end to end in local Docker Compose · synthetic data

  • Stack: Azure Data Factory, ADLS Gen2, Azure Databricks, PySpark, Azure SQL, PostgreSQL

Uber Eats Data Analytics Platform

Cloud & Lakehouse Engineering · Completed · run end to end in Azure · synthetic data

  • Stack: Azure Data Factory, ADLS Gen2, Azure Databricks, PySpark, FastAPI, Python, SQL

NovaCart Incremental Retail Lakehouse
