Streaming & Real-Time Data Engineering · Data Platform Architecture

AtlasFlow: Real-Time Logistics Control Tower

CDC-driven logistics control tower: PostgreSQL changes are captured by Debezium, streamed through Kafka, processed by three Flink SQL jobs into Bronze, Silver and Gold Iceberg tables and served through Trino for Superset.

Distinguishing feature: Gold is rebuilt as one current-state row per shipment, with an explainable, rule-based risk classification.

Completed · run end to end in local Docker Compose · synthetic data

  • PostgreSQL
  • Debezium
  • Apache Kafka
  • Apache Flink
  • Apache Iceberg

Cloud & Lakehouse Engineering · Data Platform Architecture

HealthGrid Data Platform

Metadata-driven Azure platform: an Azure SQL control plane selects each source's FULL, APPEND or MERGE load, a file-ingestion manifest and watermarks prevent repeat loads, and audit controls record every stage from landing to Gold.

Distinguishing feature: The MERGE only updates a row when the incoming source version is newer, and fails on an equal-version conflict.

Completed · run end to end in Azure · synthetic data

  • Azure Data Factory
  • ADLS Gen2
  • Azure Databricks
  • PySpark
  • Azure SQL
  • PostgreSQL
